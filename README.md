# Visualizador de capas de apostilas

Catálogo React/Vite que carrega `public/apostilas_url_capa-imagem.csv` e exibe as capas do acervo.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação na Vercel

Importe este repositório na Vercel. A configuração padrão é suficiente: a Vercel detecta o Vite, executa `npm run build` e publica `dist`.
